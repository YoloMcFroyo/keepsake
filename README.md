# Keepsake

Keepsake is an [Expo](https://expo.dev) project using
[Expo Router](https://docs.expo.dev/router/introduction).

## Get started

Install dependencies:

```bash
npm install
```

Start the app:

```bash
npx expo start
```

The app currently has one route at `src/app/index.tsx`. The root layout is in
`src/app/_layout.tsx`.

## Checks

```bash
npx expo lint
npx tsc --noEmit
```
